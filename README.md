Welcome to a small gravity 'simulation' project I did for a mini gamejam !

Stick around to see how I try to optimize it using SIMD and miserably fail.


To compile, create a `build` folder at the root of the project and call `cmake ..` from inside of it.
You might want to enable compiler optimizations doing the same thing but using `cmake CMAKE_BUILD_TYPE=Release ..`.
now you only need to call `make` and it should work !
Have fun !
